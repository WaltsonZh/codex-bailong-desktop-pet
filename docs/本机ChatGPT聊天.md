# 本机 ChatGPT 聊天

本功能属于本地 1.6.0 源码，尚未公开发布。README 的 1.4.2 正式下载入口仍有效，公开程序仍需配置兼容的模型接口。

在聊天页点击顶部服务栏，打开右上角服务管理，选择「添加本机 ChatGPT」并保存。已有接口配置和聊天记录会保留；服务管理可切回原接口。模型通过选单选取，打开服务页后在后台读取本机当前账户的可用文字模型；列表较长时可以搜索，也可点击「刷新」。选择「使用本机默认模型」则跟随本机默认设置。只有点击保存才提交选择。

读取列表失败时保留已有选择和本次读取成功的旧列表，并显示原因；不会自动改选其他模型。已保存但未出现在当前列表中的型号会标注「原设置」，以免升级或临时读取失败覆盖设置。离开页面会取消读取，迟到结果不会覆盖新页面。读取模型目录不发送聊天消息；原有兼容接口仍填写该服务的模型名称。

模型下方可以选择「推理强度」。档位来自该模型实际返回的能力；选择本机默认模型时，会读取本机实际配置来匹配能力。选择「使用默认强度」沿用 harness 的默认设置，其他选择随消息发送，只在白龙中保存，不修改桌面 ChatGPT 的全局配置。

用户主动切换到不支持原强度的模型时，选单改为默认强度并提示，保存后生效。普通后台刷新和失败保留原选择；如果刷新确认当前模型已不支持所选档位，保存前需重新选择。原服务配置缺少强度字段时仍使用默认行为。

连接复用桌面 ChatGPT 随附的本地运行程序及其当前登录状态，无需填写 API 地址和密钥。请先安装、打开并登录 Windows 桌面 ChatGPT。请求仍通过网络使用 ChatGPT 账户的模型及额度，不是离线模型。登录过期或额度不足时会提示原因，等待用户主动重试。

每次发送只提交当前白龙对话中受历史条数、字符上限限制的上下文，以及白龙角色提示词；不会读取其他 Codex 对话来拼接上下文。角色提示词、高级超时和历史上限仍在原入口配置。本连接用于文字聊天，工具和确认操作请使用桌面 ChatGPT。

回复会逐步显示。停止、切换对话、清空或删除时中断本次请求；迟到结果不会重新加入历史。只有完整成功的回复才写入白龙历史。失败保留上条用户消息，可使用重试。每次请求使用临时运行目录和临时 harness 会话，不在桌面应用中积累白龙会话，聊天历史仍由白龙用户目录保存。

实现通过桌面安装内的 `codex.exe app-server` 使用 JSON-RPC，不复制或保存 ChatGPT OAuth 凭据，不开放额外网络监听端口。发现、读取和退出进程均在后台执行，闲置时没有聊天专用的常驻进程或轮询。

协议依据：[OpenAI Docs 的 app-server 文档](https://learn.chatgpt.com/docs/app-server)，可用型号及强度通过 `model/list` 获取并读取全部分页，不硬编码示例型号或模型能力；显式强度通过 `turn/start.effort` 传入。实际兼容性以本机随附程序为准；已验证版本见 HANDOFF。

相关回归：`python tools/check_source.py test_chat_harness test_chat_config test_chat_config_ui test_chat_transport test_large_chat_ui test_process_launch`。这些自动测试使用合成服务和独立用户目录，不访问真实账户；真实请求与原生界面检查另行记录。
